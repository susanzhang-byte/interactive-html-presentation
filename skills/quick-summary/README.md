# Quick Summary

A standalone, visual-first ChatGPT summarization Skill for videos, articles, transcripts, and plain text.

## Install
Use the included `SKILL.md` wherever ChatGPT Skills are supported. If your GPT setup uses instruction/knowledge files rather than Skills packages, copy the contents into the GPT's instructions or attach the file as appropriate.

## Use
Send a link, transcript, or text and ask: "Use Quick Summary to summarize this."

## Output
- Compact title and metadata
- TL;DR
- Scannable, clickable topic index
- Expanded topic explanations with technical analogies and business implications
- Video/transcript timestamps when verified; important short quotes for plain text

**No website or archive integration is included.**
